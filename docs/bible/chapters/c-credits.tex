\chapter{Crédits et licences des composants}\label{chap:credits}
LHUNA repose sur le travail de nombreux projets libres. La table ci-dessous est générée à partir des fichiers de
licence présents dans les sources ; le texte complet de chaque licence accompagne le code source et figure dans
l'écran « À propos » de l'application.
Base de l'application : \texttt{zxtune}, sous LGPL~v3.
\input{gen/credits}
\begin{technique}
La bibliothèque libvgm (dossier \texttt{vgm}) et les cœurs qu'elle contient (Nuked, MAME, Ootake, EMU2413\dots)
n'ont pas de fichier de licence unique dans les sources : la licence de chaque cœur doit être vérifiée
individuellement avant publication de l'APK sous GPL~v3.
\end{technique}
