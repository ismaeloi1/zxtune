\chapter{Limites connues}
Nous préférons vous dire ce qui ne marche pas encore plutôt que de vous laisser le découvrir.
\begin{itemize}
  \item Android Auto affiche au plus 32 voies : au-delà, les dernières ne sont pas montrées.
  \item Les fichiers Saturn SSF et PlayStation PSF n'ont pas encore de vue détaillée par voix ; leur oscilloscope
        montre la sortie générale.
  \item La vue PC Engine ne sert que pour les enregistrements VGM ; les fichiers HES utilisent la vue générique.
  \item Les réglages marqués « applied to the next track » ne changent pas le morceau en cours.
  \item L'interface est en anglais uniquement. Les traductions existantes sont conservées dans les sources mais ne
        sont plus livrées, faute de pouvoir les tenir à jour.
  \item Le MT-32 a besoin des images mémoire du module d'origine, que nous ne fournissons pas.
  \item Nous ne développons pour l'instant que la version Android ; la version de bureau suit avec du retard.
\end{itemize}
