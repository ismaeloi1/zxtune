\chapter{Installation and first launch}

\section{Installing the APK}
\soft is distributed as an APK file.
\begin{enumerate}
  \item Copy the file to the phone, or download it directly.
  \item Open it. Android asks to allow installation from this source: accept for this time.
  \item An update installs over the previous version; playlists and settings are kept.
\end{enumerate}

\section{Permissions}
\begin{description}
  \item[Storage] to read music on the phone. On recent Android versions, \soft asks for access to a specific folder
        rather than to the whole storage.
  \item[Notifications] for the playback notification and the progress of folders being added to playlists.
\end{description}

\section{Tour}
The application has three screens, reached from the bottom bar:
\begin{enumerate}
  \item \textbf{Now playing}: current track, visualisation and controls.
  \item \textbf{Playlists}.
  \item \textbf{Browser}: your files and online catalogues.
\end{enumerate}
