\chapter{Version history}
This appendix summarises the main steps of \soft development, most recent first. Numbers are those of the
development builds delivered for testing.

\section*{Version 40}
\begin{itemize}
  \item Interface entirely in English.
  \item SID: the Mod column names the source voice only (``Sync V1'', ``Sync+Ring V1'').
\end{itemize}
\section*{Version 39}
\begin{itemize}
  \item PC Engine view: waveform shape named (sine, triangle, rising or falling saw, square, pulse), table number and
        range.
\end{itemize}
\section*{Version 38}
\begin{itemize}
  \item PC Engine view: level bar and panning bars.
  \item SID: the samples lane sits under the voices of its chip; the three voices no longer contain samples played
        through the volume.
  \item AdLib OPL/OPL2: nine voices in 3~$\times$~3, drum lanes hidden by default.
\end{itemize}
\section*{Version 37}
\begin{itemize}
  \item PC Engine: per-voice output and HuC6280 state in the Ootake core; dedicated view with each voice's wavetable
        and all its registers.
\end{itemize}
\section*{Version 36}
\begin{itemize}
  \item Fullscreen portrait: top cutout and bottom corners avoided, dashboard correctly placed.
  \item SID: the Mod column names the source voice of sync and ring.
\end{itemize}
\section*{Version 35}
\begin{itemize}
  \item Oscilloscope height and filter response height settings.
  \item SID: optional samples lane (\$D418).
  \item Live panel: SNES page.
\end{itemize}
\section*{Versions 33 and 34}
\begin{itemize}
  \item Multiple playlists, favourites, adding from the player, the browser and playlists.
  \item Play next queue, M3U import and export, $\equiv$+ button in the player.
  \item Multi-song files played directly from the browser.
  \item SID: optional mono output for 2SID and 3SID tunes.
\end{itemize}
\section*{Versions 30 to 32}
\begin{itemize}
  \item Super Nintendo: ares (cycle-accurate) emulation by default, snes\_spc as an option, for SPC and SNSF.
\end{itemize}
\section*{Earlier versions}
\begin{itemize}
  \item SID filter response view in the oscilloscope, without value texts.
  \item SCSP effects DSP enabled: reverb of Sega arcade boards and the Saturn.
  \item Dashboard values in real time, frame by frame.
  \item Technical track information (codec, rate, bit depth, bitrate), compact bottom area.
  \item Selectable FM cores per family, platform presets and analogue output stage.
  \item YMW258 and SCSP PCM chip view.
  \item Extended WAV (PCM and floating point).
  \item LHUNA identity: navigation bar, mini player, settings as cards, About screen.
  \item Vulkan and OpenGL ES oscilloscope with thin traces, window fitted to each voice period.
  \item FM inspector (OPN, OPM, OPL) and S-DSP view.
\end{itemize}
