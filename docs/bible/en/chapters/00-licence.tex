\section*{Proprietary drivers}
The author's music drivers (\emph{NebulaWeave} family) are not part of the base APK. They are distributed in a
separate APK under a proprietary license.
\begin{itemize}
  \item Without that APK, \soft works exactly as described in this manual.
  \item With that APK installed, \soft can use the drivers it provides.
\end{itemize}
For both licenses to coexist, the drivers APK must remain a separate work under GPL~v3: it runs in its own process and
talks to \soft through a documented interface (Android service, content provider, data). Loading its native library
into the \soft process would make the whole a single work, which would then have to be entirely under GPL~v3.
