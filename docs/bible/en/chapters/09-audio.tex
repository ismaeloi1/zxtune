\chapter{Recorded audio formats}
Besides emulated music, \soft plays common audio formats:
\begin{itemize}
  \item WAV: 8 to 32-bit PCM, 32-bit floating point, extended header (WAVE\_FORMAT\_EXTENSIBLE);
  \item FLAC, Monkey's Audio, Musepack, TAK (lossless);
  \item MP3, Ogg Vorbis, Opus, AAC, AC-3;
  \item and game audio formats supported by vgmstream (previous chapter).
\end{itemize}
For these formats, Now playing shows codec, sample rate, bit depth and bitrate.
