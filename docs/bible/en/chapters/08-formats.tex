\chapter{Music formats}
\soft recognises \lhunaModulesCount{} music formats. We generated the table below from the application itself, so it
is exact for the version described.

Behind that number lie four very different ways of keeping music. Knowing which one a file belongs to tells you what
to expect: a tracker module always plays back identically, a register recording holds only what was captured, a rip
runs the machine's real program and so reacts to the emulation in every detail.

\begin{description}
  \item[Tracker module] score and instruments, replayed by a player faithful to the original one;
  \item[Register stream] sequence of values written to the chip registers, logged from the machine;
  \item[Memory dump] original player program run on an emulated processor (Z80, 6502\dots);
  \item[Multichip] several chips played together.
\end{description}
``Game audio stream'' refers to audio formats of modern games (CRI, Nintendo, Sony, Wwise\dots): compressed recordings
read by the vgmstream library.
