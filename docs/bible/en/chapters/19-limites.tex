\chapter{Known limitations}
We would rather tell you what does not work yet than let you find out.
\begin{itemize}
  \item Android Auto shows at most 32 lanes: beyond that, the last ones are not shown.
  \item Saturn SSF and PlayStation PSF files do not have a detailed per-voice view yet; their oscilloscope shows the
        overall output.
  \item The PC Engine view only serves VGM recordings; HES files use the generic view.
  \item Settings marked ``applied to the next track'' do not change the current track.
  \item The interface is in English only. Existing translations are kept in the sources but no longer shipped, since
        we cannot keep them up to date.
  \item The MT-32 needs the original module's memory images, which we do not supply.
  \item For now we only develop the Android version; the desktop version follows with a delay.
\end{itemize}
